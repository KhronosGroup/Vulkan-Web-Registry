# Vulkan-Web-Registry

**NOTE:** As of December 2024, this repository has been archived. A new repository,
https://github.com/KhronosGroup/Vulkan-Registry, is now being used as the backing store for the Vulkan API and Extension Registry. This repository is retained since it
contains the published specification artifacts for all versions of the Vulkan
Specification preceding Vulkan 1.4.
